# Лапки — учебный каталог пристройства животных

Небольшой функциональный MVP для самостоятельного изучения и дальнейшей визуальной доработки. Все восемь анкет, имена, возраст, особенности и статус животных вымышлены. Лицензированные фотографии служат иллюстрациями: это **не реальные объявления** и не сайт настоящего приюта.

## Запуск

Нужен Node.js 22.12+; для нового окружения подходит Node.js 24 LTS. Зависимости зафиксированы в `package-lock.json`.

```sh
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173. Секреты, аккаунты, API-ключи и переменные окружения не нужны. `.env.example` описывает это явно.

Production build и локальный просмотр:

```sh
npm run build
npm run preview
```

Открыть http://127.0.0.1:4173. Готовый самостоятельный сайт находится в `dist/`. Его можно обслуживать обычным Nginx на своём VPS, без Sites, Vercel или аккаунта ChatGPT. [Инструкция self-hosting](docs/SELF_HOSTING.md).

## Что можно попробовать

- Подобрать животных по виду, квартире/дому, детям от 7 лет, другим животным, активности, возрасту, первому опыту и особому уходу. Условия объединяются. Неизвестная совместимость не трактуется как положительная.
- Открыть содержательную анкету: характер, распорядок, уход, ограничения и атрибуция фотографии.
- Сохранить анкеты в избранное и вернуться к ним после перезагрузки.
- Пройти три шага демо-заявки: дом → знакомство → проверка. Кнопка «Заполнить демо-данными» позволяет обойтись без настоящих контактов. Ошибки показаны у полей, шаг назад сохраняет введённые значения.
- При несовпадении условий увидеть предупреждения. Они не изображают одобрение или отказ приюта.
- Завершить сценарий, получить локальное подтверждение, проверить историю и сбросить демо-данные.

Форма **ничего не отправляет**, не вызывает email/API и не связывается с приютом. Имя, email и текст доступны только во время открытой формы; после завершения удаляются из её состояния. История содержит только `id`, `petId`, `createdAt` и максимум 30 подтверждений. При недоступном localStorage работа продолжается в памяти с явным предупреждением.

## Данные и архитектура

Статическое приложение на React + TypeScript + Vite. Tailwind CSS используется для стилей, Phosphor — для иконок. Шрифты системные; все фото локальные, аналитики и обязательных внешних запросов нет.

```text
src/data/pets.ts             вымышленные seed-анкеты
src/data/photo-credits.json  источники, авторы, лицензии и изменения фото
src/domain.ts               подбор, валидация, подсказки, проверка хранимых данных
src/storage.ts              localStorage; сохранение только разрешённых полей
src/App.tsx                 каталог, избранное, история, состояние окна
src/components/             фильтры, карточка, профиль, диалог, заявка
src/styles.css              палитра, композиция и адаптивность
public/photos/              восемь лицензированных JPEG
tests/scenarios.spec.ts     браузерные сценарии desktop/mobile
```

Серверной базы данных нет. Избранное и подтверждения принадлежат конкретному браузеру и origin; на другом устройстве или поддомене они не появятся. Для сброса используйте «Сбросить демо-данные» внизу страницы: удаляются только ключи `lapki-demo:favorites:v1` и `lapki-demo:receipts:v1`. Seed-анкеты не меняются.

В поддерживающем браузере необязательный WebMCP-модуль предоставляет чтение демо-анкет, открытие профиля и замену локального избранного через то же состояние интерфейса. Поддержка браузерного API не требуется для сайта. Нативная интеграция не является обещанной совместимостью: тестируется контракт с имитацией реестра, а весь пользовательский сценарий работает обычными кнопками.

`.openai/hosting.json` — необязательная метаинформация приватного preview. На обычную сборку и self-hosting она не влияет, токенов там нет.

## Проверки

```sh
npm run typecheck
npm test
npm run build
npm run check:public
npx playwright install chromium --only-shell
npm run test:e2e
```

На Linux для браузерных системных зависимостей: `npx playwright install --with-deps chromium --only-shell`.

Unit-тесты проверяют комбинации условий, неизвестную совместимость, валидацию и восстановление повреждённых данных. Браузерные тесты проверяют полный сценарий заявки без сетевой отправки, избранное после перезагрузки, клавиатуру/Escape/возврат фокуса, заблокированное хранилище, локальные фото, мобильную ширину, увеличение текста до 200% и доступность через axe. Автоматические проверки доступности не заменяют аудит со скринридером. [Результаты проверки v1](docs/VALIDATION.md).

## Ограничения MVP

Нет реального каталога, операторов приюта, авторизации, backend, отправки заявок, уведомлений, синхронизации или админки. Характер, здоровье и совместимость придуманы и не являются фактами о животных на фотографиях. Советы в анкетах служат содержимым учебного сценария; они не заменяют оценку реального животного.

На этой версии проверяется Chromium. Docker/Nginx-конфигурация подготовлена для переноса; реальный VPS, домен и production-развёртывание не создавались. Доступность из РФ зависит от выбранного VPS/сети и требует отдельной проверки после реального размещения.
